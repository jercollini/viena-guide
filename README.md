# Viena en 4 días

Travel guide site for a 4-day trip to Vienna, by **Viajes J.R. Collini**.
Built with the private `travel-guide-kit`.

Live: https://jercollini.github.io/viena-guide/

City content lives in `src/guide/`. `npm test` checks the data,
`npm run dev` runs it locally, and every push to `main` deploys to GitHub Pages.
